# 配置

- `username`：1–64 个英文字母、数字、下划线或连字符。
- `password`：至少 20 字符的独立密码；不允许换行或 NUL。建议使用密码管理器生成，不要复用 HA 密码。
- 网络端口：默认 5033/tcp，可在 HA 应用配置中修改；客户端填写相同端口。

数据保存在此应用的 `/data`，正常重启、容器替换或升级保留。卸载前如需保存历史，先制作包含本应用的 HA 备份。

容器日志不会主动打印密码。分享 HA 配置、备份或截图前仍须自行检查是否包含凭据。

# 排错

- 无法启动：先检查日志和密码长度，确认端口没有被旧的本地加载项占用。
- 401：客户端填写的独立用户名或密码不匹配。
- 连接被拒绝：确认应用正在运行、使用的是 HA 主机的局域网 IP 和映射后的端口。
- 没有更新：HA 中刷新仓库，再检查 GitHub Actions 是否启用及上次维护结果。上游镜像变化必须通过候选测试才能发布。

服务端不带入站 HA 登录页面；它使用自己的 Basic Authentication。客户端访问可信局域网之外的服务时，应通过已有的安全通道或配置 HTTPS。
